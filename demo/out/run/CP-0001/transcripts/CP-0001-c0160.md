**Worked analysis, keeping three things apart:**

*What it was for.* The gatekeeper recorded arrivals and departures so the mill could dock wages. It was written for management's bookkeeping, not to describe workers' lives.

*What it shows about discipline.* The mill enforced punctuality and set penalties. Pell appears three times in four days for the same offence, and the foot note suggests repeat offenders were passed up to a manager. That last point is inference, since the note doesn't say what would happen.

*What it's silent about.* It can't show who was late but unnoticed, whether Pell had a reason, or how the men felt about the docking. The blank March 5-9 isn't evidence of perfect behavior. The margin note suggests nobody was fined because nobody was working. Note that the note is in a different hand from the main entries, so someone other than the gatekeeper explained the silence.
