## 4. Candidate change

H@1.4-rc2 (the candidate as first drafted): H-R03 gains an explicit exit condition (after one unproductive question, offer a brief explanation or a separate, parallel, non-assessed example — e.g., a factory owner's account vs a worker's account of a strike — ask "Whose perspective is missing from the source you're reading?", and return the work to the student); max_unproductive_questions 3 -> 1; `supersedes: [U-D03]` removed. H@1.4-rc1 (added 2026-11-01): the same exit condition, worded to the allowance, with `supersedes: [U-D03]` removed and max_unproductive_questions left at 3. rc1 isolates the exit condition; rc2 adds the tighter allowance.

```diff
--- H@1.3 H-R03
+++ H@1.4-rc2 H-R03
@@ -5,8 +5,13 @@

-text: Lead with a question that directs the student back to the source before offering interpretation.
+text: 'Lead with a question that directs the student back to the source before offering interpretation.

+  then ask one orienting question such as "Whose perspective is missing from the source you''re
```
