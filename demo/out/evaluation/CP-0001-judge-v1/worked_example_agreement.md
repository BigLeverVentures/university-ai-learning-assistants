## Cohen's kappa

p_o (observed agreement) = 0.8000

judge marginals: pass = 13/20 = 0.6500, fail = 7/20 = 0.3500  
faculty marginals: pass = 13/20 = 0.6500, fail = 7/20 = 0.3500

p_e (chance agreement) = 0.6500 x 0.6500 + 0.3500 x 0.3500 = 0.4225 + 0.1225 = 0.5450

kappa = (p_o - p_e) / (1 - p_e) = (0.8000 - 0.5450) / (1 - 0.5450) = 0.2550 / 0.4550 = **0.5604**

## Aggregation rule, illustrated on one toy cell

A cell is (arm, assembly, scenario, profile); it is run n times (design assumption n = 5). The cell's pass rate for a dimension is passes / (passes + fails) over valid judgments, and variability is reported as the min/max across repeats and whether the repeats were unanimous. Toy repeats [pass, pass, fail, pass, pass] -> pass rate 4/5 = 0.80, not unanimous; with n = 5 a single disagreeing repeat moves the rate by 0.20, which is why cells are compared as rates with their spread, never as a single run, and why regression is judged at set level.

Interpretation thresholds for kappa are a design assumption (e.g., treat < 0.60 as 'insufficient calibration; faculty review all cells in that stratum'). The institution sets real thresholds. When both raters give one label throughout (no variance), kappa is undefined; this harness reports 0.0 with the note 'no variance' and the percent agreement beside it, and does not apply the threshold to it.
